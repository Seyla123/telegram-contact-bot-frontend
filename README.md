# Telegram Contact Bot Frontend

A real-time communication platform built with Vue.js and Laravel that enables seamless Telegram user interactions and contact management.

## Features

- Real-time two-way communication between Telegram users
- Contact information storage and management
- Message history tracking and storage
- User-friendly interface for managing conversations
- Real-time data synchronization with Laravel backend
- Secure API integration

## Tech Stack

Frontend:

- Vue.js 3 - Progressive JavaScript framework
- Telegram Bot API - For Telegram integration
- Laravel Echo - For real-time communication
- Pusher.js - WebSocket client
- Pinia - State management
- Vue Router - Navigation
- Axios - HTTP client

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn
- Telegram Bot Token
- backend API endpoint
- Pusher account credentials
